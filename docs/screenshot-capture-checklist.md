# Screenshot Capture Checklist

Use this checklist while capturing visuals for `docs/competition-management-guide.md`.

## Capture Settings
- Resolution: keep consistent per device type
- Browser zoom: 100%
- Theme: dark (current app default)
- Use seeded demo data for stable examples
- File format: PNG

## Naming Convention
- Folder: `docs/assets/screenshots/`
- Pattern: `area-purpose-state.png`
- Example: `admin-participants-toolbar-mobile.png`
